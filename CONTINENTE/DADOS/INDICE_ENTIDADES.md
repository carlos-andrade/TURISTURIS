Data de consolidação: 2026-10-04

## Objetivo

Este índice liga a estrutura territorial existente aos registros turísticos normalizados que serão consolidados em CONTINENTE/DADOS.

## Fontes internas já disponíveis

### Estrutura territorial

CONTINENTE/DISTRITO/

Contém a hierarquia por distrito e município utilizada como base territorial.

### Pontos turísticos

CONTINENTE/PONTOS_TURISTICOS/

Camada transversal destinada ao catálogo de pontos turísticos.

### Registros municipais

Os READMEs municipais existentes em CONTINENTE/DISTRITO constituem a primeira camada editorial/territorial de entidades e pontos turísticos. Esses conteúdos devem ser gradualmente normalizados para o esquema canônico deste diretório.

## Critério de promoção

Uma entidade só deve passar da camada editorial/territorial para um registro canônico quando houver:

1. identificação inequívoca;
2. município/localização definidos;
3. fonte identificável;
4. estado de validação;
5. data de verificação;
6. tratamento explícito dos campos voláteis.

## Não duplicação

O índice é catálogo de referência, não uma segunda fonte de verdade. O Layout Mestre continua sendo a autoridade estrutural e as fontes verificadas continuam sendo a autoridade factual.
