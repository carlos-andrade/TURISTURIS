# ALOJAMENTOS — Fonte e ingestão nacional

Esta pasta controla as fontes e o processo de ingestão de alojamento turístico de Portugal.

## Fontes primárias

- RNET — empreendimentos turísticos registados no Turismo de Portugal.
- RNAL — estabelecimentos de alojamento local registados no Turismo de Portugal.

## Fonte estruturada

Os dados georreferenciados oficiais do Turismo de Portugal são disponibilizados através de serviços ArcGIS REST com consulta estruturada.

## Regra

Nenhum registro deve ser criado por inferência. A origem oficial deve acompanhar o registro desde a ingestão até à publicação.
