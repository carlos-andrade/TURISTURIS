# DISTRITOS DE PORTUGAL

## Objetivo

Esta pasta centraliza a estrutura territorial dos **18 distritos de Portugal Continental** utilizada pelo TURISTURIS.

Os **Açores** e a **Madeira** não são distritos; são Regiões Autónomas e deverão ser tratados separadamente no modelo territorial do projeto.

## Estrutura territorial TURISTURIS

A hierarquia territorial adotada pelo projeto é:

**Portugal → Região → Distrito/Arquipélago → Município → Localidade → Entidade**

Cada distrito deverá futuramente receber os respetivos:

- municípios;
- localidades;
- pontos turísticos;
- património;
- alojamentos;
- restaurantes;
- transportes;
- experiências;
- eventos;
- roteiros;
- serviços turísticos;
- fontes e evidências;
- data de verificação;
- estado de validação;
- grau de confiança.

## Regiões Autónomas

As seguintes unidades territoriais fazem parte de Portugal, mas **não devem ser classificadas como distritos**:

- Região Autónoma dos Açores
- Região Autónoma da Madeira

Serão organizadas no TURISTURIS como **arquipélagos/regiões autónomas**, mantendo a mesma lógica territorial e de dados do LAYOUT MESTRE.

## Regra de dados

Nenhuma informação turística será considerada validada apenas pela presença nesta lista. Este arquivo estabelece a **estrutura territorial**, enquanto os dados das entidades turísticas deverão seguir as regras de fontes, verificação, proveniência e validação definidas nas CARTAS e no LAYOUT MESTRE.
