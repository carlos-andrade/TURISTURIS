# CARTA DE ATUALIZAÇÃO — TURISTURIS

## Regras
1. Informação volátil deve ser revisada antes de ser apresentada como atual.
2. Alterações devem preservar informação anterior quando houver valor histórico.
3. A data de verificação acompanha dados sensíveis ao tempo.
4. Informações conflitantes não devem ser silenciosamente sobrescritas.
5. A atualização deve indicar a fonte que motivou a alteração.
6. Dados arquivados não devem ser confundidos com dados atuais.

## Prioridade de revisão
Alta: horários, preços, contactos, encerramentos, transportes e disponibilidade operacional.
Média: descrição, serviços, acessibilidade e instalações.
Baixa: contexto histórico estável e descrição geográfica estável.
