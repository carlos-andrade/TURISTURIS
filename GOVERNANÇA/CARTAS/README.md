# CARTAS

Pasta oficial das Cartas do projeto TURISTURIS.

As Cartas transformam as decisões e regras originadas pelos prompts em normas documentadas do projeto.

## Hierarquia

**PROMPT → CARTAS → LAYOUT MESTRE → ESTRUTURA → DADOS → CÓDIGO/SITE**

A CARTA REGENTE possui precedência sobre as Cartas especializadas.

## Documentos

- `CARTA_REGENTE.md`
- `CARTA_PARA_CARTAS.md`
- Cartas especializadas do domínio.

Toda nova Carta deve respeitar a CARTA PARA CARTAS e não pode contradizer a CARTA REGENTE sem uma revisão formal.
