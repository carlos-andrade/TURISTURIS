# LAYOUT

Pasta oficial dos Layouts do projeto TURISTURIS.

O Layout transforma as regras das Cartas em uma estrutura operacional que orienta dados, artefatos e código.

## Regra central

O **LAYOUT MESTRE** é a referência estrutural canônica do TURISTURIS.

Fluxo oficial:

**PROMPT → CARTAS → LAYOUT MESTRE → ESTRUTURA → DADOS → CÓDIGO/SITE**

## Documentos

- `LAYOUT_MESTRE.md`: fonte estrutural principal.
- Novos layouts devem ser criados nesta pasta.
- Layouts especializados devem declarar sua relação com o LAYOUT MESTRE.

## Regra de consistência

Nenhum Layout especializado pode contradizer o LAYOUT MESTRE. Alterações estruturais devem ser registradas e versionadas no Git.
