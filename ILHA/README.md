# ILHA

## Objetivo

Estrutura canônica para organizar o turismo insular de Portugal.

## Escopo inicial

Esta pasta será organizada por ilha, mantendo a mesma lógica territorial e de dados definida no LAYOUT MESTRE.

## Regra estrutural

Cada ilha terá uma pasta própria. Dentro dela serão organizados destinos, pontos turísticos, alojamentos, restauração, transportes, experiências, eventos, roteiros e fontes conforme a necessidade e os dados disponíveis.

## Estado

Estrutura inicial criada em 2026-10-04.
