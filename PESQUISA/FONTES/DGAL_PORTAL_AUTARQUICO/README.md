# DGAL — Portal Autárquico

Fonte oficial para investigação futura no TURISTURIS.

## Fonte
- Portal: https://portalautarquico.dgal.gov.pt/
- Entidade: Direção-Geral das Autarquias Locais (DGAL)

## Utilização prevista
1. Referência administrativa oficial de municípios e freguesias.
2. Validação da hierarquia territorial Município → Freguesia.
3. Apoio à reconciliação territorial dos registos RNAL.
4. Investigação futura de Áreas Metropolitanas, Comunidades Intermunicipais e outras entidades locais.
5. Avaliação de dados institucionais/financeiros quando forem relevantes para módulos posteriores.

## Aplicação imediata prevista
TOMAR — usar a DGAL como fonte de referência territorial para a FASE A2, sem inferência destrutiva de freguesia.

## Regra
A DGAL não deve ser tratada como fonte RNAL sem verificação específica. Primeiro confirmar quais conjuntos de dados/campos são disponibilizados e a respetiva cobertura.

## Relação com outras fontes
- Turismo de Portugal — dados turísticos estruturados.
- Município de Tomar — fonte municipal de alojamentos.
- DGAL — referência administrativa territorial.
- RNAL — identificação/registo do alojamento.
