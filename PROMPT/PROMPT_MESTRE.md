# PROMPT MESTRE — TURISTURIS

## 1. Finalidade

Estabelecer o padrão único para criação, registro, revisão e execução dos prompts do TURISTURIS.

## 2. Princípio fundamental

**Tudo começa com um PROMPT.**

O prompt formaliza a necessidade antes da criação ou alteração de documentos, dados, estruturas, automações, código ou publicação.

## 3. Fluxo obrigatório

1. PROMPT
2. CARTAS
3. LAYOUT MESTRE
4. ESTRUTURA
5. DADOS
6. VALIDAÇÃO
7. CÓDIGO/SITE
8. PUBLICAÇÃO, quando aplicável

## 4. Requisitos mínimos

Todo prompt relevante deve registrar:

- objetivo;
- escopo;
- entidades envolvidas;
- fontes esperadas;
- restrições;
- resultado esperado;
- critérios de aceitação;
- necessidade de atualização de Carta;
- necessidade de atualização de Layout;
- data de criação;
- estado.

## 5. Regra de não-invenção

O prompt não autoriza a criação de fatos sem fonte. Informações turísticas devem seguir a CARTA DE FONTES, a CARTA DE DADOS e o LAYOUT MESTRE.

## 6. Rastreabilidade

Cada execução que produza artefatos no repositório deve ser rastreável ao prompt que originou a alteração.
