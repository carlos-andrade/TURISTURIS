# PROMPT

Pasta oficial para todos os prompts do projeto TURISTURIS.

## Regra de origem

Todo novo trabalho do TURISTURIS começa por um **PROMPT**.

Sequência oficial:

**PROMPT → CARTAS → LAYOUT MESTRE → ESTRUTURA → DADOS → VALIDAÇÃO → CÓDIGO/SITE**

Nenhum código, estrutura definitiva ou publicação deve ser tratado como fonte primária antes de existir o prompt que define a necessidade.

## Organização

- `PROMPT_MESTRE.md`: regras gerais para criação e evolução de prompts.
- Novos prompts devem ser criados nesta pasta.
- Cada prompt deve possuir objetivo, escopo, entradas, saídas esperadas, critérios de validação e data.

## Regra de precedência

Um prompt não pode contradizer a CARTA REGENTE ou o LAYOUT MESTRE. Quando houver necessidade de alteração estrutural, o prompt deve originar a revisão formal das Cartas e, depois, do Layout.
