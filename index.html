Uma arquitetura orientada por dados

O projeto foi concebido para transformar informação turística dispersa em informação estruturada e reutilizável.

CARTAS → LAYOUT MESTRE → DADOS → CÓDIGO

O Layout Mestre funciona como referência operacional para novos artefatos. A informação deve possuir proveniência identificável e os dados voláteis devem ser datados.

Informação com rastreabilidade

O objetivo é construir uma base turística consultável, atualizável e auditável, mantendo separadas a coleta, a organização, a validação e a apresentação.
